# Sayuri Yukishiro — обязательный порядок работы агента

Перед любым изменением проекта прочитать:

1. docs/UPDATE_PROTOCOL.md
2. UPDATE_IDS.json
3. UPDATE_LOG.md
4. PROJECT_STATE.json

Обязательные правила:

- сначала назначить новый CHG-ID и нужный типовой ID;
- не переиспользовать номера;
- BUG регистрировать до FIX;
- FIX всегда должен ссылаться на BUG;
- работа должна быть привязана к development_version;
- после изменения выполнить проверки;
- только после проверок финализировать версию;
- обновить журнал сразу;
- записать implementation commit SHA;
- перед завершением записать один однозначный next_action.

CI-проверка протокола:

python scripts/validate_update_protocol.py

Нарушение протокола считается дефектом процесса и исправляется до следующего этапа.
